# SmartTasks

Projeto pedagógico de gestão de tarefas para a empresa fictícia TaskFlow (25 colaboradores).

**Estado:** especificação do primeiro MVP aprovada; a aplicação, os testes e os ficheiros Docker ainda não foram implementados.

4. [User Stories](docs/04_user_stories.md)

O MVP prevê Python/FastAPI, uma interface HTML, gestão de tarefas em memória e execução local em Docker. PostgreSQL, autenticação, CI/CD e observabilidade avançada não fazem parte desta entrega.
